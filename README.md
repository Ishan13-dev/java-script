## How to Run

You can run the JavaScript files using Node.js.

1. Clone this repository:

```bash
git clone https://github.com/Ishan13-dev/java-script-var-str.git
```

2. Open the repository folder in VS Code.

3. Open the terminal and execute any JavaScript file:

```bash
node filename.js
```

Replace `filename.js` with the actual JavaScript filename.
