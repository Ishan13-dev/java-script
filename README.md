# JavaScript Variables & Strings 🟨

A beginner-friendly JavaScript learning repository focused on understanding variables, strings, and the fundamentals of storing and manipulating data in JavaScript.

## 📌 About the Project

This repository contains practical JavaScript examples and exercises covering variables and strings.

It is designed to help beginners understand how to declare variables, assign values, work with different types of strings, and perform basic string operations.

## 📚 Topics Covered

### 1. JavaScript Variables
- What are variables?
- Variable declaration using `var`, `let`, and `const`
- Variable initialization and reassignment
- Difference between `var`, `let`, and `const`
- Variable naming conventions
- Understanding variable scope

### 2. JavaScript Strings
- Introduction to strings
- Single quotes (`' '`)
- Double quotes (`" "`)
- Template literals (`` ` ` ``)
- String concatenation
- String interpolation
- Escape characters

### 3. String Methods
- `length`
- `toUpperCase()`
- `toLowerCase()`
- `slice()`
- `substring()`
- `replace()`
- `trim()`
- `includes()`

## 💻 Code Examples

### Variables

```javascript
let name = "Ishan";
const age = 21;
var city = "India";

console.log(name);
console.log(age);
console.log(city);
```

### String Concatenation

```javascript
let firstName = "Ishan";
let lastName = "Verma";

let fullName = firstName + " " + lastName;

console.log(fullName);
```

### Template Literals

```javascript
let name = "Ishan";
let language = "JavaScript";

console.log(`Hello ${name}, welcome to ${language}!`);
```

### String Methods

```javascript
let message = "  Hello JavaScript  ";

console.log(message.length);
console.log(message.toUpperCase());
console.log(message.toLowerCase());
console.log(message.trim());
```
